# Fake Netflix

Cvičný projekt, na kterém se učím Next.js, React a TypeScript.
Data o filmech jsou zatím uložená přímo v projektu, ne v databázi.

## Technologie
- Next.js (App Router)
- React
- TypeScript
- Tailwind

## Co umí
- seznam filmů s vyhledáváním podle názvu
- řazení podle názvu, hodnocení a délky
- detail filmu
- seznam režisérů a detail režiséra

## Spuštění
```bash
npm install
npm run dev
```
Pak otevři http://localhost:3000
